# 🌐 Grupo Aleph

*Três empresas, uma cadeia completa do fornecedor ao destino.*

O **Grupo Aleph** reúne três empresas complementares que, juntas, cobrem toda a jornada de um produto no comércio internacional: quem negocia, quem move e quem nutre. Este repositório traz os quatro sites do grupo, todos modernos, responsivos e trilíngues (Português, Inglês e Espanhol).

&nbsp;

## 🚀 Sobre o Projeto

➽ Quatro sites integrados sob uma mesma identidade visual
➽ Site institucional do grupo + um site dedicado para cada empresa
➽ Suporte completo a três idiomas (PT / EN / ES) com seletor que lembra a escolha
➽ Design cinematográfico, responsivo e sem dependências pesadas
➽ Navegação interligada: cada site leva aos outros três

&nbsp;

## 🏢 As Empresas

➽ **Aleph Comex** — Comércio exterior: trading importadora e exportadora que conecta pequenas e médias empresas ao mercado internacional
➽ **AlephLog** — Logística internacional: transporte, despacho aduaneiro e um network exclusivo em 30 países
➽ **Aleph Agro** — Nutrição vegetal: importação e distribuição de fertilizantes especiais com tecnologia patenteada para cada cultivo

&nbsp;

## ✨ Destaques

➽ **Globo 3D interativo** no site do grupo, que gira, responde ao mouse e mostra os polos globais do network
➽ **Cadeia animada por scroll**, montando a operação do fornecedor ao destino
➽ **Vitrine premium** das três empresas com painéis que expandem
➽ **Fichas técnicas reais** no Aleph Agro: 14 cultivos e 19 produtos com dados de nutrição
➽ **Conteúdo real** de cada empresa, e não texto genérico

&nbsp;

## 🧠 Tecnologias Utilizadas

HTML • CSS • JavaScript • Three.js • Google Fonts • GitHub Pages

&nbsp;

## 📂 Estrutura do Repositório

```
grupo-aleph/
├── index.html              → redireciona para o site do grupo
├── grupo_aleph_site/       → site institucional do grupo (flagship)
├── aleph_comex_site/       → site da Aleph Comex
├── aleph_log_site/         → site da AlephLog
└── aleph_agro_site/        → site da Aleph Agro
    ├── index.html
    ├── css/styles.css
    └── js/main.js
```

Cada site é independente e traz sua própria pasta `css/` e `js/`, com o código separado e organizado.
